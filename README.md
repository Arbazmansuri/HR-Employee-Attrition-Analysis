# HR Employee Attrition Analysis Dashboard

## Project Overview
An interactive HR dashboard built using Python to analyze employee attrition and identify possible reasons employees leave an organization.

## Features
- Total employee and attrition KPIs
- Department-wise attrition analysis
- Overtime analysis
- Job role and age group analysis
- Monthly income analysis
- Interactive dashboard filters
- Business insights and recommendations
- Data quality checks

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Streamlit

## How to Run
Install the required libraries:

pip install streamlit pandas matplotlib

Run the dashboard:

streamlit run "Untitled-1.py"
